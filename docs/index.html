BMuster

Self-hosted remote access for every machine you look after. Reach the desktop and terminal of your Windows and Linux machines from any browser, phone included, on a server you run yourself.

{% include hero-art.html %}

Install the server with one command in Terminal:

curl -fsSL https://bmuster.com/install.sh | sudo sh

Run it on the machine that will host BMuster: a Raspberry Pi, a virtual machine or a spare PC. It installs BMuster as a service and shows the address to open.

Downloads and release notes are on GitHub Releases. Free code signing provided by SignPath.io, certificate by SignPath Foundation (code signing policy).

What it does

BMuster is one place to reach and look after a fleet of computers, from a handful to hundreds. You run the server; a small agent on each machine phones home over HTTPS, so there are no ports to open on the machines themselves.

  • Remote desktop and terminal in the browser, built mobile-first so it works from your phone
  • Unattended access for IT staff, with a notice on the machine and a Disconnect button while someone is connected
  • Inventory for every machine: hardware, operating system, GPUs and who is signed in
  • Users, groups and access rules that decide who can reach which machines and what they can do
  • Sign in with a password, or with Microsoft 365 or Authentik, and an activity log of who did what
  • Works on a private network too, with its own pinned certificate when there is no public domain

How it works

Step 1

Install the server

Run the command above on a Raspberry Pi, a virtual machine or a spare PC, Linux or Windows. Then open it and create your admin account.

Step 2

Add your machines

Your server's Add machine page gives a one-line command with a join code. Run it on each computer to install the agent.

Step 3

Connect from anywhere

Open your server in a browser, pick a machine and open its desktop or terminal.
